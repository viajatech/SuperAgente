# Security Policy

## Maintainer

This project is maintained by David Ruiz (GitHub: @viajatech), who is responsible for its security and handles all vulnerability reports.

## Reporting a vulnerability

Please do not report security issues in public issues. Use the "Report a vulnerability" button in this repository's Security tab.

I aim to acknowledge reports within 7 days. Confirmed vulnerabilities will be fixed and disclosed once a patch is available, crediting the reporter if they wish.

## Supported versions

Security fixes are applied to the latest version on the main branch.
